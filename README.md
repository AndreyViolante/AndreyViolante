## Featured Projects

### [est-robot](https://github.com/AndreyViolante/est-robot)

Reverse engineering of an educational robot (Dr. Luck EST) with no public documentation. Captured and analyzed USB traffic to map the robot's HID protocol, then built a Python compiler that translates plain Python scripts into the robot's byte-level program format &mdash; removing the dependency on the proprietary IDE.

`Python` &middot; `Reverse Engineering` &middot; `HID Protocol` &middot; `Robotics`

### EnglishTutor &nbsp;&middot;&nbsp; [live app](https://englishtutor-weld.vercel.app)

AI-powered English tutoring app for Brazilian middle school students (grades 6&ndash;9). An animated virtual teacher holds conversations by text and voice &mdash; speech recognition for the student, text-to-speech for the teacher &mdash; adapting the whole session to the student's grade and selected curriculum topics, across explanation, role-play and critical-thinking modes.

The teaching model is socratic by design: the assistant answers a question with a guiding question first and only explains after the student tries. Since the audience is minors, the system prompt enforces explicit safety boundaries around health topics. Built with React Native and Expo, running on Android, iOS and the web, with the language model served through the Groq API.

`React Native` &middot; `Expo` &middot; `TypeScript` &middot; `LLM` &middot; `Speech Recognition`

> Developed as the software component of an undergraduate thesis in Languages and Literature. The source repository is private; the application is publicly available at the link above.

### [RegionWatcher](https://github.com/AndreyViolante/RegionWatcher)

Native Android app that watches a user-defined rectangle of the screen and raises an alert when its content changes. A foreground service captures frames through MediaProjection, crops the selected region, computes a perceptual hash (dHash) and compares it against the reference by Hamming distance, with configurable sensitivity and debounce to suppress repeated alerts.

`Kotlin` &middot; `Jetpack Compose` &middot; `MediaProjection` &middot; `Perceptual Hashing`

### [estudos-backend](https://github.com/AndreyViolante/estudos-backend)

Three REST APIs exploring distinct backend patterns: relational CRUD with PostgreSQL, integration testing against a real database with pytest, and event-driven order processing with MongoDB, RabbitMQ and Kafka. All services containerized with Docker.

`FastAPI` &middot; `PostgreSQL` &middot; `MongoDB` &middot; `RabbitMQ` &middot; `Kafka` &middot; `Docker` &middot; `pytest`

### [biblioteca](https://github.com/AndreyViolante/biblioteca)

Library catalog management system built with Django, focused on advanced filtering over the collection.

`Python` &middot; `Django` &middot; `SQLite`
